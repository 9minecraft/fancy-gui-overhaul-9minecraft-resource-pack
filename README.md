# Fancy GUI Overhaul — Sleek Dark Menus and Warm Wood

Fancy GUI Overhaul 9minecraft Resource Pack restyles the game interface with sleek dark panels and warm wooden textures. It refreshes every container screen, inventory menu, and survival HUD element for a neat look. You get clear icons, matching workstation interfaces, and uncluttered frames across all your survival tools without needing any extra mods.

Gives every workstation and container menu a fresh, clean visual style. Transforms the crafting table menu into a warm wooden scroll layout.

## What this build is

An unofficial rebuild of **botanydev**'s original work, kept running on current Minecraft releases by 9Minecraft Studios. Not affiliated with the original author and not endorsed by them.

Keeping a pack alive across releases is not a copy-paste job: each Minecraft version bumps the pack format and shuffles texture and model paths, so the tree gets re-mapped and every asset re-checked against the version it is built for. Anything the new release dropped is rebuilt rather than left pointing at a path that no longer exists.
